## 사전 조건

이 커맨드 실행 전, `/review-pr-triage $ARGUMENTS` 결과에서 **[수용] 항목 목록만** 아래에 붙여넣는다.

```
[수용] 항목 목록:
- (triage 결과 붙여넣기)
```

## 작업 지시

### 1. 코드 수정

- 위 [수용] 항목만 순서대로 코드에 반영한다.
- 반려 항목은 건드리지 않는다.

### 2. 테스트 확인

- 수정된 파일과 관련된 테스트만 실행한다.
- CLAUDE.md의 테스트 실행 규칙을 따른다.

### 3. 작업 완료 후

- 수정된 변경사항을 커밋하고 PR 브랜치에 푸시한다.
