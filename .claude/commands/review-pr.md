PR $ARGUMENTS번의 gemini-code-assist 리뷰를 검토하고 대응한다.

## 작업 지시

### 1. 리뷰 파악
- PR $ARGUMENTS번의 전체 리뷰 코멘트를 확인한다.
- gemini-code-assist가 남긴 리뷰 코멘트를 식별하고 목록을 정리한다.
- 각 코멘트의 수정 필요 여부를 판단한다.

### 2. 리뷰 검토 코멘트 작성
- 각 리뷰 항목에 대해 검토 의견을 PR 코멘트로 작성한다.
- 코멘트 작성 시 `@gemini-code-assist` 를 언급한다.
- 수용할 항목, 수정할 항목, 반려할 항목을 명확히 구분하여 작성한다.

### 3. 코드 수정
- 수용하기로 한 리뷰 항목을 실제로 수정한다.
- 수정 후 테스트가 있는 경우 테스트 통과 여부를 확인한다.

### 4. 작업 완료 후
- 수정된 변경사항을 커밋하고 PR 브랜치에 푸시한다.
