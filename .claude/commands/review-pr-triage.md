PR $ARGUMENTS번의 gemini-code-assist 리뷰를 파악하고 대응 계획을 수립한다.

## 작업 지시

### 1. 리뷰 파악

- PR $ARGUMENTS번의 전체 리뷰 코멘트를 확인한다.
- gemini-code-assist가 남긴 리뷰 코멘트를 식별한다.

### 2. 분류 결과 출력

각 코멘트를 아래 형식으로 분류하여 출력한다. **코드 수정은 하지 않는다.**

```
[수용] 파일명:줄번호 — 코멘트 요약 (수정 방향 한 줄)
[반려] 파일명:줄번호 — 코멘트 요약 (반려 이유 한 줄)
```

### 3. PR 코멘트 작성

- 각 리뷰 항목에 대해 검토 의견을 PR 코멘트로 작성한다.
- 코멘트 작성 시 `@gemini-code-assist`를 언급한다.
- 수용할 항목, 반려할 항목을 명확히 구분하여 작성한다.
