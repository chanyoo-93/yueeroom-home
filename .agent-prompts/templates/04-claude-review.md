현재 브랜치의 변경 내역을 검토해줘.

참고:

- 현재 브랜치는 issue #{{ISSUE_NUMBER}}의 구현이다.
- docs/plans/issue-{{ISSUE_NUMBER}}-plan.md가 있다면 참고하되, 커밋 대상 여부도 확인해줘.

관점:

- 책임 분리가 적절한가?
- 기존 아키텍처와 어긋나는 부분이 있는가?
- 중복 코드가 생겼는가?
- 테스트가 충분한가?
- 향후 유지보수 위험이 있는가?
- 보안/인증/응답 계약 변경이 있다면 회귀 위험이 있는가?

주의:

- 바로 수정하지 말고 리뷰 의견만 작성해줘.
- 파일을 변경하지 마.
- 반드시 심각도별로 분류해줘.

출력 형식:
[Critical]

- ...

[High]

- ...

[Medium]

- ...

[Low]

- ...

[종합]

- PR 가능 여부
- 릴리즈 전 반드시 처리할 항목
- 선택적으로 처리할 항목
