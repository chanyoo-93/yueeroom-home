docs/plans/issue-{{ISSUE_NUMBER}}-plan.md 파일을 읽고 GitHub repository issue #{{ISSUE_NUMBER}} 작업을 준비해.

아직 코드는 수정하지 마.

출력:

1. 네가 이해한 작업 목표
2. 수정 대상 파일
3. 구현 순서
4. 테스트 추가/수정 계획
5. 위험 요소
6. 작업 시작 전에 확인이 필요한 점

주의:

- issue-{{ISSUE_NUMBER}}-plan.md의 범위를 벗어난 제안은 하지 마.
- 계획서에서 “변경 불필요” 또는 “수정 금지”로 언급된 파일/함수는 변경하지 않는 것으로 간주해.
- 현재 git status를 확인하고, 계획 문서가 untracked인지 여부도 보고해.
- 이 단계에서는 파일을 수정하지 마.
