#### 플로우 2 — 상품 → 장바구니/바로주문 → 주문 → 결제 (부분 완료)

| 단계                                         | 상태                                    |
| -------------------------------------------- | --------------------------------------- |
| 상품 상세 페이지 정상 렌더링                 | ✅ (2026-05-09)                         |

**Stripe 결제 테스트 재개 방법**:

1. `https://yueeroom.com`에서 테스트 계정으로 로그인
2. 상품 상세 → 바로 주문 또는 장바구니 → 결제
3. "신용카드" 선택 → 테스트 카드 `4242 4242 4242 4242`, 유효기간 미래, CVC 임의
4. 결제 완료 → 주문 상태 `PAID` 확인 (webhook 비동기, 5~10초 후 새로고침)
5. `/orders`에서 주문 내역 확인

#### 플로우 3 — 환불 ❌ 미진행

1. 완료된 주문에서 환불 요청 (`POST /api/orders/:id/refund`)
2. 주문 상태 `REFUNDED` 변경 확인
3. Stripe 대시보드에서 환불 내역 확인

#### 플로우 4 — 관리자 대시보드 ❌ 미진행

1. `admin@yueeroom.com`으로 로그인
2. 매출 통계 (`GET /api/admin/stats/sales`) 데이터 반환 확인
3. 주문 목록 (`GET /api/admin/orders`) 반환 확인
4. 주문 상태 변경 (`PATCH /api/admin/orders/:id/status`) 확인
5. 미승인 회원 목록 (`GET /api/admin/users/pending`) 확인

## 네이버페이 연동 보류

**원인**: ECS 컨테이너에 아래 환경변수 3종이 미주입됨

```
NAVER_PAY_CHAIN_ID   ← SSM·ecs.tf 없음
NAVER_CLIENT_ID      ← SSM·ecs.tf 없음
NAVER_CLIENT_SECRET  ← SSM·ecs.tf 없음
```

**해결 조건**: 네이버페이 파트너 계정(Chain ID) 확보 필요.

**확보 후 처리 순서**:

1. `aws ssm put-parameter`로 SSM에 3개 파라미터 등록
2. `infra/terraform/ecs.tf` secrets 블록에 3개 추가
3. `terraform apply` → ECS 롤링 배포

**현재 상태**: 네이버페이 UI는 활성화된 채로 두되, 오류 발생 시 사용자가 다른 결제 방법으로 변경 가능 (PR #135로 수정됨).
