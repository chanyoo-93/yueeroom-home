# 토큰 절약 규칙

## 출력 형식

- 답변은 간결하게 (~함., ~했음. 형식)
- 사용자 지정 형식이 없으면 3줄 이내
- 사용자 지정 형식이 있으면 반드시 준수
- 테스트 결과는 최종 결과만 출력

## 파일 읽기

- 같은 세션 내 이미 읽은 파일 재읽기 금지
- 파일 전체 읽기 전 Bash grep/find로 대상 줄 확인 후 offset/limit으로 필요 범위만 읽음

## 탐색 및 실행

- 단순 조회는 직접 Bash 사용, Agent 스폰은 병렬 처리·컨텍스트 보호가 필요할 때만
- ls로 디렉토리 존재 확인 등 명백한 검증 단계 스킵
